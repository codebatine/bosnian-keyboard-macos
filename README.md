# Bosnian Keyboard for macOS

Bosnian keyboard layout for macOS with golden lilies flag (zlatni ljiljani) for the menu bar.

## Features

- Bosnian Latin keyboard layout
- Support for č, ć, ž, š, đ
- Bosnian flag icon
- Compatible with macOS keyboard input sources
- No third-party application required

## Installation

1. Click **Code → Download ZIP** on this GitHub repository.
2. Extract the downloaded ZIP.
3. Open **Finder**.
4. Press `Cmd + Shift + G`.
5. Enter `~/Library/Keyboard Layouts/`.
6. Copy both `Bosnian.keylayout` and `Bosnian.icns` into that folder.
7. Log out and log back in, or restart your Mac.
8. Open **System Settings → Keyboard → Text Input → Edit**.
9. Click **+**, find the Bosnian layout, and add it.
10. Select the keyboard using the input source icon in the macOS menu bar.
